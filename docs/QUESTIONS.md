# Вопросы и заглушки

## Заглушки для подключения администратором

- `[TELEGRAM]` — ссылка на Telegram-канал/бот. Рабочая гипотеза: `t.me/pg_mk_bot`, финальный адрес подтверждает МБ.
- `[FORM_ACTION]` — endpoint формы. Подключается к Битриксу pressgurwitz.art, комментарий `<!-- BITRIX_FORM -->`.
- `[BITRIX_CHECKOUT_URL]` — ссылка на оплату сертификата.
- `[PHONE]` — телефон Press Concept.
- `[EMAIL]` — email для связи.
- `[HOURS]` — часы работы.
- `[DATE_1]`, `[TIME_1]` и т.д. — конкретные даты расписания.
- `[ЦЕНА]` — цена для формата 10–12 лет с родителем, устанавливается МБ.
- `<!-- METRIKA -->` — код Яндекс.Метрики.
